# 灰の砲手

スマートフォン横画面向けの、見下ろし型アクション。外部ライブラリ、API、ビルド処理、音源への依存はありません。

## 起動・公開

リポジトリルートで `python3 -m http.server 8016` を実行し、`http://localhost:8016/ash-gunner/` を開いてください。`ash-gunner/` 内の `index.html`、`style.css`、`core.js`、`art.js`、`game.js` を同じフォルダーに置くだけで静的ホスティングから起動します。サブディレクトリにも対応しています。

## 操作

- スマホ：左下スティックで移動。右下の叩きつけ・突進・回避を使います。左右の指を別のPointer IDで扱います。
- PC：WASDで移動、Jで叩きつけ、Kで突進、Spaceで回避。
- 突進・回避は移動方向、入力がなければ最後に向いた方向へ出ます。秒数と塗りでクールダウンを表示します。
- 上部のⅡで一時停止。タブ離脱や縦向きへの切り替えでも停止して入力を解除します。

## 遊びの流れ

小型敵の集団を2回突破→突進距離か叩きつけ範囲の強化→直進か弾薬庫破壊→漫画の対面→砲手戦。先にボスだけ遊ぶ「砲手との稽古」も用意しています。

直進は威力+30%・最大HP+40。敵はHP半分から2連射。寄り道は弾薬庫を実際に壊す必要があり、追加自己強化の代わりに2連射を封じます。両ルートともクリア可能です。

射線が出た時点で砲手の狙いは固定されます。砲弾は最初に当たる柱で止まり、柱は3発で崩れます。弾は連続線分で衝突判定し、速い弾のすり抜けを防いでいます。装填中は砲身が下がり、蒸気・表示・残り時間の線が出ます。この隙の攻撃は1.6倍。二連射は各弾に独立した予告が出ます。漫画コマ中に戦闘は進みません。

1プレイの目安は3〜5分。腕前や選択で変わります。敗北・勝利後の「もう一度」は同じ開始モードで全状態をリセットします。保存・BGM・効果音は実装していません。

## 描画と構成

画像を背景として貼り付けず、紙の粒、外周の瓦礫、キャラ、柱、弾、エフェクトをCanvasで個別に描画しています。添付の雰囲気に合わせた輪郭・斜線によるオリジナルの簡略描画で、参考画像ほど緻密な完成イラストではありません。`art.js` の `guard`、`gunner`、`pillar` 相当の描画と背景関数を差し替えて、スプライトを導入できます。

`core.js`：DOMに依存しない進行・戦闘・衝突判定。
`game.js`：入力・画面・ゲームループ。
`art.js`：描画。背景はオフスクリーンで一度作成。
`style.css`：横画面HUD、Safe Area、縦向き案内。

## 検証

`node --test ash-gunner/tools/core.test.cjs`

Python PlaywrightとChromiumを用意し、サーバー起動後に `python3 ash-gunner/tools/browser_check.py` を実行できます（Chromiumのパスはスクリプト内）。スクリーンショットと結果は `/workspace/artifacts/ash-gunner/` に出力されます。

柱の3発破壊・弾の停止・固定照準・装填中の反撃・突進命中・複数敵への攻撃・分岐・勝敗をルールテストで確認します。ブラウザではタイトルから両ルートを自動操作し、勝利・敗北・リトライを確認します。CDPの独立した2点のタッチ入力で、移動を保持したまま攻撃し、指を離すと停止することを確認します。

スマートフォン実機は利用できないため、実機Safari/Android Chromeでの二本指動作は未確認です。Chromiumのモバイルエミュレーションと横画面4サイズ、縦向き案内で確認しています。
