# 残墨（ざんぼく）

縦持ちの2D剣戟アクション。抜刀で引いた墨へ敵を誘い、納刀でまとめて断つ。静的ファイルだけで動きます。既存のゲームから独立したディレクトリです。

## 起動

Nodeライブラリのインストールは不要です。Python 3 があれば起動できます。

```sh
cd zanboku
python3 -m http.server 8017
# http://localhost:8017/
```

または `npm run dev`。スマホで同じLANの `http://開発PCのIP:8017/` を開きます。回転・全画面・インストールは不要です。

## 操作

- 左下のスティックで移動。右下の３ボタンは移動しながら同時に操作できます。
- **斬る**：前方を薙ぐ。押し続けると連続斬り。雑兵は一撃、鐘守は攻撃後の隙に有効。
- **抜刀**：入力方向へ約205pxすり抜け、実際の経路に墨を引く。入力なしでは直前の向き。２回は短い間隔で出せ、２回目の後は少し息を整えます。
- **納刀**：その瞬間、幅40pxの墨と足元が重なる敵を斬る。墨は２本まで、４秒で消滅。鐘守へ２本同時に重ねると大きなダメージとひるみ。３本目は古い線を消す。
- PC：WASD / 矢印で移動、Jで斬る（長押し可）、Kで抜刀、Lで納刀。Escで一時停止。
- 朱の予告は攻撃する方向。予告が出てから狙いは固定されるので、横へ避ける。
- 第一陣30人、第二陣36人、第三陣16人と鐘守。敵の同時出現は雑兵19体まで、攻撃の構えは同時２体まで。陣を抜けると命が１つ回復。
- 鐘守は半分以下で二打の鐘に合わせた速い踏み込み。最初の鐘で構え、二打目の鐘と同時に攻撃。音を消しても判断できます。
- 勝敗後は「もう一度、斬る」で再戦。戦闘データは毎回リセット。自己最多一閃と消音設定だけ端末に保存します。

プレイ時間は戦い方によって変わります。約90秒を設計上の目安とし、慣れた自動操作では30秒台で突破できます。実際のプレイ時間は操作の習熟で変わります。

## 公開

`zanboku/` の **index.html / style.css / core.js / art.js / sound.js / game.js / assets/** を同じ相対位置で静的ホスティングへ配置します。GitHub Pagesでリポジトリごと公開する場合は `/game/zanboku/` です。バックエンド、外部ライブラリ、音楽API、APIキーは不要です。

```sh
npm run build
```

公開用だけを `zanboku/dist/` にコピーします。Netlify / Cloudflare Pagesではこのフォルダを配信可能。`npm install` は不要です。`dist` は生成物なのでGitには含めません。

共有カード設定は index.html の og:* / twitter:*。別のURLで配信する場合は絶対URLを変更してください。共有画像は assets/share.jpg。添付の戦闘絵にある人数表示はゲームのスコアとして読み取りません。

## 構成

- core.js：純粋な戦闘シミュレーション。ヒット判定、敵AI、波、墨の消費と消滅。
- art.js：画像アセット指定、描画、斬撃、雨、着弾表現。描画の墨幅は判定と同じ定数を使用。
- sound.js：開始タップ後に起動するローカル音響。消音時・音声非対応時も戦闘は正常に進行。
- game.js：画面、HUD、複数Pointerの入力、キー操作、保存、共有。
- assets/provenance.json：添付画像と生成画像の利用先。

## 検証

```sh
npm test                 # Node標準テストのみ。依存なし。
node tools/bot.mjs        # 実際の技・移動だけで全３陣を通すシミュレーション
npm run build            # 静的配信物を生成
```

ブラウザ統合テストは Python Playwright とシステム Chromium のある環境で実行します。

```sh
ZANBOKU_URL=http://127.0.0.1:8017 python tests/browser_check.py
```

`?test` を付けたときだけ検証用の状態参照を公開します。通常URLではデバッグUIも検証機能も表示しません。ブラウザテストは実際のキーボードとCDPの複数タッチ接触で操作し、勝つために敵のHPや進行フラグを書き換えません。

検証環境・確認結果は `VERIFICATION.md` に記載しています。

## 2026-11-17 動作・UI改修

浪人は走り・振り抜き・追撃・納刀の姿勢を使い分けます。抜刀には短い残像、まとめ斬りには一瞬の寄りと墨の飛沫、敵には倒れる方向と水面の波紋を追加。画面を激しく揺らし続けず、端末の「視差効果を減らす」設定では寄りと残像を抑えます。

UIは丸いボタンの面と二重枠を除き、筆文字と細い墨線に変更。技のタップ領域、墨の本数、クールダウン、一時停止と消音は維持しています。筆文字フォントは同梱しており、外部フォント配信やAPIへの接続はありません。
