# 灯をつなぐ旅

スマートフォン向けの小さなコマンドRPG。第一章「風鳴りの古道」を収録しています。4人から3人を選び、盾崩し・印・大技の順番を組み立てて戦います。

## 起動

外部ライブラリやバックエンドは不要です。リポジトリのルートで次を実行してください。

```sh
python3 -m http.server 8006
```

`http://localhost:8006/tomori/` を開きます。HTML/CSS/JavaScriptと配布済み画像をそのまま配信する構成のため、インストールやバンドルのビルド工程はありません。

## 収録内容

- 4人から3人を編成。先頭が身構えると単体攻撃から仲間をかばいます。
- 道中3戦、途中の選択、橋のボス戦、章の結末、強くなったボスとの再戦。
- 各人2種類の技、SP管理、回復薬、レベルアップ、武器の手入れ2段階。
- 技のコスト・盾の状態・選択中の敵の次の行動を表示。敵をタップすると詳細が切り替わります。
- 選択による最大HPまたはボスの盾の変化、結末の文章の変化。
- 会話送り、既読会話のスキップ、手帳からの振り返り。
- 行動ごとの自動保存、戦闘途中の再開、破損記録から直前の正常な保存への復旧。
- 片手で押しやすい44px以上の操作領域、セーフエリア、縦画面・横画面、演出を抑える設定。

第一章以降は未実装です。オンライン機能や音声はありません。武器の手入れは攻撃力を上げる仕組みです。

## ファイル

- `data.js`：キャラクター、技、敵、ステージ、会話の内容。
- `core.js`：表示に依存しない戦闘、進行、保存データの検証。
- `game.js`：画面、操作、保存、アニメーション。
- `styles.css`：スマートフォン向けレイアウト。
- `assets/`：配布用WebP。構えと攻撃のフレームを分け、武器も同じ絵の中に描いています。
- `credits.html`：素材・保存・収録範囲の説明。

素材は本作向けの生成画像です。原画の記録は `assets/provenance.json` に記載し、技術的な切り出し・縮小は `tools/prepare_assets.py` に分離しています。この処理は原画PNGがある開発環境用で、ゲームの起動には不要です。旧デザインの見本は公開ファイルに含めていません。

## 検証

```sh
node --test tomori/tools/core.test.cjs
```

10件：連携のダメージ、印の消費、複数ヒット、かばう、無効操作、途中保存、勝敗時の回復と報酬、両ルート、4種類の編成、ボス会話と再戦、保存データ検証。

ブラウザ検証は、任意でPlaywrightのPythonパッケージとChromiumが使える環境で実行できます。

```sh
python3 tomori/tools/browser_check.py --url http://localhost:8006/tomori/
```

Chromium上で両ルートを実際のボタン操作からクリアし、編成・強化・手帳・再戦・撤退と再挑戦・途中再開・破損保存の復旧を確認しました。320×568、390×844、430×932、768×1024、844×390、1280×900の画面サイズで表示と操作領域を確認しています。通常の攻撃フレーム・矢の飛翔・メニュー中の敵行動停止も確認しました。iPhone/Android実機でのSafari/Chromeの確認はまだ行っていません。

保存キーは `tomori-journey-v1`。ブラウザ内に保存され、サーバーへ送信しません。画像生成APIへの実行時の通信もありません。
