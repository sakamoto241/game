# うたのない国 — 第1章・導入版

「知っているはずの物語が、少しだけおかしい。」

TypeScript / Phaser 3 / Vite による、スマートフォン縦画面の探索アドベンチャー。既存ゲームから独立したプロジェクトです。

## この版で遊べること

- 絵本のタイトル画面、はじめから・つづきから・設定。
- **森の入口、どんぐり広場の2エリア**を往復して探索。
- 地面をタップして歩行。障害物を避け、住人や調査対象には歩いて近づいてから反応。
- ウタウサギの分岐会話、どんぐりとの交流、状態によって変わる看板や椅子の調査。
- 落ち葉の収集・詳細・選択使用・タッチドラッグによる使用。絵本に挟むと景色と手がかりが変化。
- 地図・目的・手がかり帳・段階別ヒント。地図の移動先を選ぶと出口まで歩行。
- 会話の途中も含むオートセーブ、既読スキップ、文章速度・音量・動きの設定。
- 統一した水彩絵本素材、独立した透過キャラクター、歩行アニメーション、控えめな落ち葉演出。
- 任意再生のオリジナル・オルゴールBGM。歌声・外部の録音・生成API接続はありません。

**第1章全体の完成版ではありません。** 池のほとり・池の中・長老の家、橋の修理・宝物・物語のループ、最後の2つの選択、章クリアは未実装です。完成版15〜20分のプレイ時間を満たすものではありません。先へ進めない道では、この導入版の範囲を説明します。第2章以降は実装していません。

## 起動

Node.js 24 を推奨（最低22.18）。

```sh
cd utanokuni-src
npm install
npm run dev
```

開発URLは `http://localhost:5173/`。スマホ実機からは同じネットワークにある開発PCのIPアドレスへ接続します。

```sh
npm test
npm run build
npm run preview
```

プレビューは `http://localhost:4173/`。`build` はTypeScriptの厳密チェック後に `dist/` へ静的ファイルを出力します。Nodeのテストは状態遷移・経路探索・保存復旧を検証します。

実際のタッチ入力・ドラッグ・会話途中の再開を確認する任意の統合テストもあります。Pythonの `playwright` とChromiumを用意し、プレビューを起動した状態で `python3 tests/browser-flow.py` を実行してください。`UTA_BASE_URL` でテスト対象URL、`UTA_ARTIFACTS` でスクリーンショットの保存先を変更できます。

制限付き環境で既定のnpmキャッシュへ書き込めない場合は、コマンドの前に `NPM_CONFIG_CACHE=/tmp/utanokuni-npm-cache` を付けてください。

## 操作

地面・住人・調べたい物をタップ。会話はタップで全文表示し、もう一度タップで次へ進みます。下部の「もちもの」から落ち葉を選び、対象をタップするか、落ち葉を対象までドラッグして使用します。選択の解除は、もちものの落ち葉をもう一度タップします。

「えほん」内の「近くのもの」から対象を選んでも、近づいて調べられます。PCのクリックでも同じ操作ができます。音楽は初期状態でオフです。タイトルの音符、または設定からオンにしてください。

## 構成

- `src/content/areas.ts` — 地図、歩行可能領域、障害物、住人・調査対象・出口。
- `src/content/dialogues.ts` — 会話本文、分岐、会話完了イベント。
- `src/core/` — UIやPhaserに依存しない進行管理、経路探索、セーブ。
- `src/engine/` — Phaser描画、歩行、入力。`placeholder.ts` は画像取得失敗時だけ使う簡易表示。
- `src/ui/` と `src/main.ts` — Safe Area対応のHTML UI、会話表示、タッチドラッグ、任意の音楽再生。
- `public/assets/` — 完成素材、透過アトラス、足元アンカー。ゲームロジックから分離。
- `public/audio/` — 同梱するオリジナルBGM。
- `public/fonts/` — OFLフォントの日本語サブセット。実行時の外部CDNは不要。
- `public/credits.html`、`public/assets/provenance.json` — 素材の由来・ライセンス。
- `tools/` — 画像の整形・アトラス化、フォント再生成、固定譜面のBGM生成。通常の起動・ビルドでは実行不要。

章追加時はまず第1章を完成させ、AreaId・マップ・会話・進行状態・保存バージョンを拡張してください。未制作章への架空のリンクや素材参照はありません。

## 保存と互換性

このゲーム専用の `utanokuni-save-v1`、`utanokuni-save-backup-v1`、`utanokuni-save-recovery`、`utanokuni-settings-v1` を使用します。ほかのゲームの記録は変更しません。

保存時に直前の有効な記録をバックアップします。破損した主記録は有効なバックアップから復帰し、両方不正な場合は明示して新規開始の確認を出します。不正な原文は新規開始時に別キーへ退避します。未知の項目や不正な座標・会話位置は検証し、試作版v0の既知の形式は移行します。将来の未知バージョンは勝手に解釈しません。保存できないブラウザでもゲームを続けられますが、終了後の復帰は保証できません。

保存は端末・ブラウザ・公開元ごとです。Cloudflare、Netlify、GitHub Pagesの間で記録は共有されません。ブラウザのデータ削除で記録も消えます。

## 公開

`base: './'` のため、ドメイン直下でもサブディレクトリでも公開できます。`dist/` 内のファイルを一式配置してください。

### Cloudflare Pages

Git連携時のRoot directoryを `utanokuni-src`、Build commandを `npm run build`、Build output directoryを `dist`、環境変数 `NODE_VERSION` を `24` に設定します。`wrangler.jsonc` は手動デプロイ用の設定です。バックエンド・APIキー・Functionsは不要です。

### Netlify

Base directoryを `utanokuni-src` に設定します。同梱の `netlify.toml` がビルド・出力先を指定します。Git連携を使わず、ビルド済み `dist/` を手動でアップロードすることもできます。

### このリポジトリのGitHub Pages

ビルド済み `dist/` を公開ブランチの `utanokuni/` に配置します。既存ゲームのHTMLやルート設定を上書きしないでください。ソースの `index.html` を直接公開しても、ブラウザはTypeScriptを実行できません。公開先を変える場合は `index.html` の `og:image` を新URLに更新してください。

Cloudflare Pages / Netlifyへの実際のデプロイには、そのサービスでのサイト作成が別途必要です。

## 素材更新と動作条件

`tools/prepare-assets.py` はプロジェクト外の画像原稿を引数で受け取ります。`--help` で用法を確認できます。原稿PNGは配布に含めず、WebPとメタデータをコミットしています。日本語の追加後は、Shippori Mincho B1のRegular/Bold原本を用意し、`tools/subset-fonts.py FONT_DIR` で文字セットを更新してください（Python fontTools/Brotliが必要）。音楽を再生成する場合のみNumPy/SciPy/ffmpegが必要です。

高DPIは最大2倍、背景は768px幅、読み込み中の進行表示あり。Phaserはタイトル表示後、ゲーム開始時に遅延読み込みします。非表示タブでは描画・音楽を停止し、復帰時の移動ジャンプを防止します。画像の取得に失敗した場合は明示して簡易表示へ切り替え、音声失敗は探索を妨げません。

iOS Safari / Android Chromeを対象とする実装ですが、ブラウザの端末エミュレーションは実機の代用ではありません。公開前後に実機でのタップ・音楽許可・Safe Areaも確認してください。
