# うしろの影

「振り返ってはいけない。でも、確認しなければ死ぬ。」

深夜の廃校を自動で歩く少女を、音と影を見極めて出口へ導く、スマホ向けの2Dピクセルアート・心理戦ホラーです。既存の静的ゲーム集に独立した `ushiro/` を追加する構成です。

## 遊べる内容

- 通常モード：72mの廊下を約60秒で脱出。1回30〜90秒を想定。
- 画面か下部ボタンをタップして振り返る。本物がいれば追い払い、いなければ恐怖が上昇。恐怖100または幽霊を放置すると失敗。
- 自分の影が二つ重なって残ることが、本物の必須の視覚的手がかり。音だけでは判定を要求しません。
- 足音・照明・窓ぎわの影・歩幅・笑い声風の風・赤い残像などの予兆とフェイント。連続するフェイントは最大2回。
- 序盤は長めの猶予。進行につれて予兆が重なり、反応猶予は徐々に短くなります。通常モードの最短猶予は約2.5秒。出現前の警告時間は別に用意。
- クリア前の一度だけの特殊な現象。本物の見分け方は最後まで同じです。
- 得点、早く見抜く反応ボーナス、連続追い払い、クリアランク。音の有無は得点に影響しません。
- 通常クリアでエンドレスを解放。最長距離を記録。猶予は1.9秒より短くしません。
- 遭遇した8種類の怪異図鑑、ローカル記録、結果の共有。
- 初回ガイド、ポーズ、音のオン・オフと音量、演出を控えめにする設定。
- 初回キャッシュ成功後は、ネット接続を切っても再読み込みから遊べるService Worker構成。

## 起動と検証

リポジトリには既存のHTMLゲームがあるため、HTML / CSS / JavaScript / Canvas APIで統一しました。外部ライブラリ・サーバー側処理・ビルド作業は不要です。

```sh
python3 -m http.server 8000
```

`http://localhost:8000/ushiro/` を開きます。スマホ実機は同じネットワークの開発PCのIPアドレスへ接続します。Service WorkerはHTTPSかlocalhostで動作します。LANのHTTP IPアドレスではオンライン動作の確認をしてください。

```sh
node --check ushiro/core.js
node --check ushiro/renderer.js
node --check ushiro/audio.js
node --check ushiro/ui.js
node --check ushiro/sw.js
node --test ushiro/core.test.cjs
```

任意のブラウザ統合テストにはPython PlaywrightとChromiumが必要です。HTTPサーバーを起動して実行してください。

```sh
python3 ushiro/tools/test-browser.py
python3 ushiro/tools/test-devices.py
```

`SHADOW_URL` と `SHADOW_ARTIFACTS` でURL・画像の保存先を変更できます。通常モードの統合テストは、実際の約60秒のゲーム進行をタッチ操作で最後まで通します。診断用 `ShadowGame.snapshot()` はコピーを読み取るだけで、進行を変更する関数は公開しません。

## ゲームの公平性

本物の幽霊は警告フェーズのあとに出現し、出現と同時に二つ目の影が表示されます。二つ目の影は追い払うか捕まるまで消えません。フェイントでこの影を表示することはありません。警告の音や灯りだけで先走って振り返ると空振りになるため、足元を見る判断が必要です。

振り返りの演出中に続けてタップしても、追加の空振りにはしません。警告中に振り返っていた場合、本物の出現は前を向くまで待つため、振り返り演出の裏で猶予を失わせません。

恐怖は空振りで26増え、追い払いで5減ります。脅威のない時間に少しずつ回復します。振り返り演出は約0.64秒。押し続けても自動連打にはなりません。

ポーズ中と非表示タブではゲーム時間が進みません。タブに戻ると1秒の猶予を設けます。リトライは距離・恐怖・予兆・ランダム状態・最終現象・スコアをすべて初期化します。

## 構成

- `core.js` — 描画や音から独立した状態、乱数、予兆、フェイント、反応猶予、勝敗、得点、保存記録の検証。
- `renderer.js` — 小さな内部解像度のCanvas描画。廊下の遠近、移動する床、左右の窓、歩行と振り返り、幽霊、二つの影、照明、ノイズ。
- `audio.js` — ユーザー操作後に開始するWeb Audio。合成した木の足音、左右の位置、距離、廊下の残響、低い環境音、笑い声のような風。
- `ui.js` — タッチ、PCのSPACE、画面遷移、ポーズ、図鑑、設定、共有、記録、低負荷切り替え。
- `index.html`、`styles.css` — Safe Area、縦画面、横画面、主要44px以上のコントロール。
- `assets/` — 元のコンセプトを基準に生成したオリジナルの透過ドット素材。人物・幽霊8フレームと校舎部品4種を低解像度にパック。
- `tools/prepare-assets.py` — 原稿の透過シートを切り分け、最近傍で縮小して配置する制作ツール。Pillowが必要。通常の起動には不要。
- `sw.js` — このゲームの範囲だけをキャッシュ。他のゲームのキャッシュや保存キーには触れません。
- `credits.html` — 絵と音の由来。

画像に失敗しても、独立したCanvasの簡易ドット表示で遊べます。描画・ロジックはアセットの文字やAI生成テキストに依存しません。

## モバイルと音

基本は縦画面。内部描画の幅は180pxで、端末の高さに合わせて描画領域を伸ばし、ピクセルを滑らかにぼかさず拡大します。低性能端末では窓の描画分割とノイズ量を減らします。60fpsを目標とする実装ですが、端末ごとの性能を保証するものではありません。

音は初回ガイドの「音を使う」で選べます。ユーザー操作後にAudioContextを開始します。音の再生許可が得られない場合も、視覚の手がかりだけでクリア可能です。足音以外の明瞭な電子ビープや歌声はありません。音の合成は端末内で行い、音声生成サービスや外部の録音へ接続しません。

## 保存とオフライン

`ushiro-shadow-profile-v1`、`ushiro-shadow-profile-backup-v1`、`ushiro-shadow-preferences-v1` に、最高記録・図鑑・設定を保存します。1回の途中状態のセーブはしません。リロードするとタイトルへ戻ります。保存不可でもその場のゲームを続けられます。

オフラインは、必要ファイルの初回保存が成功した後に有効です。設定画面に準備状況を表示します。ブラウザのデータ消去や容量整理で保存内容・オフラインデータは消える場合があります。

## 公開と更新

`ushiro/` を一式、GitHub Pages等の静的ホスティングに配置します。公開URLは `/game/ushiro/`。Cloudflare PagesやNetlifyでもビルドなしで同じフォルダを配信できます。

更新時は `sw.js` の `CACHE` バージョンを上げてください。キャッシュする必須ファイルを追加した場合は `FILES` も更新します。公開先を変える場合は、OG画像と結果共有のURLを更新してください。

## 検証結果

- コア8件のテストに合格。100通りの通常ルートが、0.55秒程度の反応で30〜90秒以内にクリア可能であることを検証。
- Chromium 390×844 / DPR2で、初回ガイド・音の許可・ポーズ・通常モードの終点・最終現象・クリア・エンドレス・恐怖による失敗・リトライ・図鑑保存まで確認。
- 320×568、390×844、430×932、768×1024、1280×900、844×390の表示・44pxコントロールと操作を確認。
- 実際にネット接続を遮断し、再読み込みしてゲームが進むことを確認。
- iPhone / Androidの実機での最終確認は未実施です。
