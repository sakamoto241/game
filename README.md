# まちと迷宮（仮題）

ドラクエ風RPG × ローグライク × 街づくり。主人公は勇者ではなく「街」。

全体ビジョンとロードマップは [design.md](./design.md) を参照。

## 開発

```bash
npm install
npm run dev        # 開発サーバー起動
npm run typecheck  # 型チェックのみ
npm run build      # 型チェック + 本番ビルド (dist/)
```

## 操作

| キー | 操作 |
| --- | --- |
| 矢印 / WASD | 移動 |
| Z / Enter / Space | 決定・しらべる |
| X / Esc | キャンセル |
| C | メニュー（つよさ・どうぐ） |
| F3 | デバッグ表示 |

## 遊び方（Phase 2 現在）

1. 村の南のポータルから「はじまりの洞窟」へ潜る（B1F〜B5F・毎回ランダム生成）
2. 敵と戦い、宝箱から ゴールド・やくそう・こうせき・ほうせき を集める
3. 「帰還のつばさ」で村へ持ち帰る（全滅すると所持金半減 + こうせき没収！）
4. こうせきとゴールドで村に施設を建てる:
   **武器屋 / 防具屋 / 酒場 / 鍛冶屋 / 市場 / 教会**（村の看板を しらべる）
5. 酒場で仲間（戦士/魔法使い/僧侶/盗賊）を勧誘して最大3人パーティに
6. 装備を買い、鍛冶屋で +3 まで強化し、より深くへ
7. B5F の「どうくつのぬし」を倒せばクリア

時間は歩くと進みます。夜は店が閉まるので宿屋（10G）で朝まで休みましょう。
倒れた仲間は教会で蘇生できます。

### 暮らしとサブコンテンツ（Phase 3）

- 村人に Z で話しかけられます。時間帯で居場所が変わり、夜は家に帰ります
- 季節（8日ごと）と天候（雨・雪・霧）があります。雨の日は釣りチャンス！
- いちばで「つりざお」を買えば池で釣り（Z でアタリを合わせる）、
  「つるはし」を買えばダンジョンの鉱脈からこうせきを採掘できます
- 夜のダンジョンは敵が増え、「さまようれい」が現れます。B3F 以降の宝箱には
  ミミックが潜んでいることも……

## ディレクトリ構成

```
src/
├── core/    # ゲーム内容を知らないエンジン層（ループ・シーン・入力・描画・乱数・セーブ）
├── gfx/     # 描画ユーティリティ（タイルマップ・テキスト）
├── data/    # データ駆動定義（タイル・マップ。今後: モンスター・アイテム・施設）
├── scenes/  # タイトル・街・ダンジョン
├── world/   # ゲーム内エンティティ（プレイヤー）
└── debug/   # デバッグオーバーレイ
```

アートは `public/assets/manifest.json` に画像を登録するだけでプレースホルダーから差し替わります。
