# まちと迷宮（仮題）

ドラクエ風RPG × ローグライク × 街づくり。主人公は勇者ではなく「街」。

全体ビジョンとロードマップは [design.md](./design.md) を参照。

## 開発

```bash
npm install
npm run dev        # 開発サーバー起動
npm run typecheck  # 型チェックのみ
npm run build      # 型チェック + 本番ビルド (dist/)
```

## 操作（Phase 0）

| キー | 操作 |
| --- | --- |
| 矢印 / WASD | 移動 |
| Z / Enter | 決定・しらべる |
| X / Esc | キャンセル・（ダンジョン内）村へ戻る |
| F3 | デバッグ表示 |

## ディレクトリ構成

```
src/
├── core/    # ゲーム内容を知らないエンジン層（ループ・シーン・入力・描画・乱数・セーブ）
├── gfx/     # 描画ユーティリティ（タイルマップ・テキスト）
├── data/    # データ駆動定義（タイル・マップ。今後: モンスター・アイテム・施設）
├── scenes/  # タイトル・街・ダンジョン
├── world/   # ゲーム内エンティティ（プレイヤー）
└── debug/   # デバッグオーバーレイ
```

アートは `public/assets/manifest.json` に画像を登録するだけでプレースホルダーから差し替わります。
