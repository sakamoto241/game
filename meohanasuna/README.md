# 目を離すな。

「見ている間だけ、あの子は止まる。」

スマホ縦画面の一人称ホラー探索・脱出ゲーム。先に生成した実写風の廊下と透過の少女を使い、同じ質感の教室・職員室を追加しています。タイトルから脱出までプレイできる独立した作品です。

## 内容

- 廊下、二年一組、職員室の3エリア。ホットスポットのタップと場所ボタンで探索。
- 少女を見ている間は接近が止まり、部屋や手がかりを調べる間は近づく。
- 長押しで廊下を確認し、指を離すと同じ調査に戻る。入力途中の数字や配電盤も保持。
- 当番表と座席表を読み合わせる番号錠、回転する配線を接続する配電盤、二つの文章から時刻を求める時計の3つの謎解き。
- 職員室と玄関の鍵、見つけた文章を読み返せる手がかり帳、段階式ヒント。
- 仕掛けを解くと少女が遠ざかるチェックポイント。捕まった場合も、解いた仕掛けや見つけた物は残る。
- 名前を思い出す任意の探索と、最後の行動による2つの結末。結末の記録と読み返し、出口前からの再挑戦。
- オートセーブ、休憩、探索速度・演出の設定、非表示タブの進行停止。

音楽・効果音・歌・実機カメラ・マイク・外部生成APIは使用しません。画像は同梱済みです。制作時の生成処理は、プレイ中には行いません。

## 起動

ビルドや依存ライブラリのインストールは不要です。リポジトリのルートで次を実行してください。

```sh
python3 -m http.server 8000
```

`http://localhost:8000/meohanasuna/` を開きます。スマホ実機では同じネットワークに接続した開発PCのIPアドレスへアクセスしてください。

```sh
node --check meohanasuna/core.js
node --check meohanasuna/game.js
node --test meohanasuna/core.test.cjs
```

任意のブラウザ統合テストにはPython PlaywrightとChromiumを使います。サーバーを起動し、次を実行します。

```sh
python3 meohanasuna/tools/test-browser.py
```

`LOOK_URL`、`LOOK_ARTIFACTS` で対象URLと画像出力先を変更できます。テストは実際のDOMコントロールとタッチ長押しを使い、両方の結末まで通します。捕まる動作のテストだけ、残り距離の少ない正規セーブを用意して長時間の待機を省略します。`LookGame.snapshot()` は診断用のコピーを返すだけで、ゲームを操作する関数は公開しません。

## 操作と時間

- 廊下を見渡している間は安全。ただし当番表などの調査パネルを開くと視線が外れます。
- 「廊下を見る」の長押し中は、調査を保持したまま廊下を見ます。PCではSPACE長押しでも使えます。ボタンのキーボード決定では視線を切り替えられます。
- 「休む」と遊び方では時間が停止します。ブラウザを隠した時間や閉じていた時間も進みません。
- 見ているだけでは少女は遠ざかりません。仕掛けの解決、または捕まった後の再挑戦で距離が戻ります。
- 「じっくり」は接近の速度を遅くします。パズルの答えと物語は変わりません。
- 手がかり帳では、見つけた文章を再読できます。「次の手がかりを考える」からヒントを3段階で表示できます。

縦画面を推奨。横画面には操作欄を右側に置くレイアウトを用意しています。

## 構成

- `index.html`、`styles.css` — 写真を広く表示するUI、調査パネル、長押し、各画面。
- `core.js` — UIに依存しない進行、経路接続判定、視線と時間、保存データ検証。
- `game.js` — 画像レイヤー、視線入力、会話・手がかり表示、保存、結末、共有。
- `core.test.cjs` — 進行と復旧のテスト。
- `assets/` — 探索背景3枚、結末の背景1枚、透過の少女3枚、素材の由来。
- `tools/prepare-assets.py` — 原稿PNGからWebPを作り、透過シートを切り分ける制作ツール。通常の起動には不要。

画像は提供された廊下の参考を基準に、この作品用に生成したものです。UIと手がかりの文章・図はHTML/CSS/SVGで描き、重要な数字や文字を生成画像に依存させていません。

## 保存

専用の `meohanasuna-save-v1`、`meohanasuna-backup-v1`、`meohanasuna-preferences-v1`、`meohanasuna-endings-v1` を使います。破損した主記録は有効なバックアップから復帰を試みます。未知バージョンや不正な状態は使用しません。

読み込めない原文がある場合、新規開始には確認を出し、原文を `meohanasuna-recovery-v1` に退避します。保存できなくてもプレイは続けられますが、画面を閉じた後の進行復帰は保証できません。端末・ブラウザ・公開ドメインごとの記録です。

新規探索でも結末の記録は残します。ほかのゲームの保存キーは操作しません。終了画面の「出口の手前から、もう一度」で、解いた謎をやり直さず別の結末を探せます。

## 公開

`meohanasuna/` を一式、静的ホスティングに置きます。公開先は `/game/meohanasuna/`。GitHub Pagesの既存公開ブランチに、このディレクトリだけを追加します。Cloudflare Pages / Netlify等でもビルドなしで同じファイルを配信できます。公開元を変える場合はOG画像と共有URLを更新してください。
